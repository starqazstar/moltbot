# 阶段一：Cursor 知识萃取探针 (.cursorrules)

## 核心设计原则
1. **静默触发**: 不打断 Vibe Coding 流
2. **结构化输出**: 标准化格式，便于后续存储
3. **三要素**: 边界假设 + 黑话翻译 + 考点参数

---

# 3. 输出触发规则
# ================================================

当我完成以下操作后，必须立即输出上述格式的知识萃取报告：

✅ 完成了某个功能模块开发

# ================================================
# 4. 输出风格要求
# ================================================

- **必须结构化**：使用 Markdown 表格和列表
- **必须接地气**：用我熟悉的场景解释抽象概念
- **必须可验证**：所有「标准黑话」必须标注来源
- **必须考试导向**：参数值必须精确，边界条件必须明确

# ================================================
# 5. 禁止行为
# ================================================

❌ 不要输出「看起来不错」「挺好的」等无信息量评价
❌ 不要跳过「核心考点参数」部分
❌ 不要使用未标注来源的黑话

# 6. 交互模式
# ================================================

我可以用以下方式触发你：

*此规则由逆向知识印钞机系统 v1.0 生成*

---

## 使用说明

1. 在 Cursor 项目根目录创建 `.cursorrules` 文件
2. 将上述配置完整复制进去
3. 开始 Vibe Coding
4. 当你完成某个功能后，说「完成了 XXX」
5. Cursor 会自动输出知识萃取报告
