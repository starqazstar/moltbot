# 阶段四：验证与复习闭环

## 设计原则
1. **被动触发**: AI 主动抽查，不增加复习负担
2. **边界质询**: 针对易错点、边界条件进行压力测试
3. **间隔重复**: 基于遗忘曲线安排复习

---

## SOP 1：日常 AI 抽查 (每日 5 分钟)

### 触发方式

**方式 A**: 快捷指令
- 快捷指令名称: 「知识小测」
- 快捷键: `⌘+Option+K`

**方式 B**: 固定时间
- cron: 每天 18:00 (下班前)
- 方式: 发送系统消息

### AI 考官提示词 (核心交付)

```markdown
# 角色设定
你是一位严苛的技术面试官，专注于云计算和大模型领域。你的任务是：
1. 从我的知识库中随机抽取 3-5 个知识点
2. 针对每个知识点进行「边界条件质询」
3. 用实际场景问题检验我是否真正掌握

# 约束条件
- 问题类型必须是「边界条件」或「失效场景」
- 禁止问定义性问题 (如「什么是 temperature？」)
- 必须给出实际场景 (如「在什么情况下 temperature=0 会出问题？」)

# 输出格式

## 本次抽查主题
[抽取的标签，如: #LLM #RAG]

## 问题 1: [知识点名称]
**场景**: [实际场景描述]

**问题**: [边界条件质询]

**我的回答**:
[等待用户输入]

**评估**:
✅ 正确 | ❌ 错误 | ⚠️ 模糊

**解析与拓展**: [正确答案 + 延伸]

---

## 抽查结束
本次抽查: 3 题
正确率: 66%
下轮复习建议: 针对 #RAG 边界条件加强
```

### 使用流程

```
1. ⌘+Option+K (触发快捷指令)
2. Shortcuts 运行 AI 抽查提示词
3. AI 随机抽取 3-5 个知识点
4. 逐一提问边界条件
5. 我回答 → AI 评估
6. 结束后给出掌握度报告
```

## SOP 3：认证考试冲刺 (考前 7 天)

### 触发方式
- 手动触发: 「进入冲刺模式」
- 持续 7 天

### AI 模拟考官提示词

```markdown
# 角色设定
你是一位阿里云 ACP 认证考官。你需要：
1. 从我的知识库中抽取认证相关知识点
2. 生成模拟真题 (单选/多选/判断/填空)
3. 每题标注「考试频次」和「易错程度」

# 约束条件
- 题目必须来自我的知识库
- 必须包含「陷阱选项」
- 必须说明「解题关键」

# 输出格式

## 模拟题 #1
**题型**: 单选题
**标签**: #LLM #Token
**频次**: ⭐⭐⭐⭐⭐
**难度**: ⭐⭐⭐

**题目**:
关于 Token 计费，以下说法正确的是？
A. 输入和输出都计费
B. 仅输出计费
C. 仅输入计费
D. 免费

**正确答案**: A

**解题关键**:
- OpenAI/Claude 都采用「输入+输出」双计费
- 计费公式: 总费用 = (输入tokens × 输入单价) + (输出tokens × 输出单价)
- 常见陷阱: 以为只有输出计费

**我的答案**: [等待输入]

---

## 冲刺进度
已完成: 10/50 题
正确率: 78%
薄弱环节: Token 相关计算
待加强: Prompt Engineering 边界条件
```

## 间隔重复策略 (核心算法)

### 简化版 SuperMemo-2

```python
# 复习调度算法
def calculate_next_review(knowledge_item, review_result):
    """
    review_result: 1-5 (1=完全遗忘, 5=轻松记住)
    """
    import math
    
    # 基础间隔 (天)
    base_intervals = {1: 1, 2: 3, 3: 7, 4: 14, 5: 30}
    
    # 计算下次复习间隔
    current_interval = knowledge_item.get('review_interval', 1)
    ease_factor = knowledge_item.get('ease_factor', 2.5)
    
    # 艾宾浩斯调整
    new_interval = current_interval * ease_factor * (review_result - 3) / 10
    new_interval = max(1, new_interval)  # 至少1天
    
    # Ease Factor 调整
    new_ease_factor = ease_factor + (0.1 - (5 - review_result) * 0.1)
    new_ease_factor = max(1.3, new_ease_factor)

        'next_review_date': add_days(today, new_interval),
        'new_ease_factor': new_ease_factor,
        'new_interval': new_interval
    }
```
